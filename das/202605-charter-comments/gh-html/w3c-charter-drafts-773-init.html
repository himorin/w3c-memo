Issue w3c/charter-drafts #773: [wg/das] Add Web Bluetooth as "Tentative Deliverable"

Initial comment by Haik Aftandilian (@hafta) at 2026-03-11 (edited in 2026-05-12)

We (Mozilla Firefox) are considering the Web Bluetooth API (Firefox bug 2022433) and thus request adding the Web Bluetooth API in the DAS WG charter "Tentative Deliverables" as follows:

Web Bluetooth API
An API to discover and communicate with devices over the Bluetooth 4 wireless standard using the Generic Attribute Profile (GATT).
Draft state: Draft Community Group Report
Adopted Draft: Adopted from Web Bluetooth Community Group
Note: This work may turn into a joint deliverable with the Web Applications Working Group.
