Comment by Marcos Cáceres (@marcoscaceres) at 2026-05-11

The implementationStatus feature is ready to use. Here's what's been done:

Vibration spec PR: #64
Adds implementationStatus: true to the ReSpec config. The Vibration API currently shows "Limited availability" (Chrome/Edge supported, Firefox/Safari not).

ReSpec enhancement PR: speced/respec#5297
Improves the widget with:

  • Gentle loading animation (300ms delay, subtle opacity pulse, respects prefers-reduced-motion)
  • Accessibility: aria-live summary region for screen readers
  • Saved documents: "More info" link becomes "Current browser support" (noun phrase matching the spec header style)
  • CLS reservation during loading

The Vibration spec PR works today with the current released version of ReSpec (the widget already functions). The enhancement PR adds UX polish that will land in a future release.
