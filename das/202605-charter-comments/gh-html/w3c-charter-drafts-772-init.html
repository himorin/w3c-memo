Issue w3c/charter-drafts #772: [wg/das] Add WebUSB as "Tentative Deliverable"

Initial comment by Haik Aftandilian (@hafta) at 2026-03-11 (edited in 2026-05-11)

We (Mozilla Firefox) are considering the WebUSB API (Firefox bug 2022432) and thus request adding the WebUSB API in the DAS WG charter "Tentative Deliverables" as follows:

WebUSB API
An API for reading and writing from a USB device through script.
Draft state: Draft Community Group Report
Adopted Draft: Adopted from WICG
Note: This work may turn into a joint deliverable with the Web Applications Working Group.
