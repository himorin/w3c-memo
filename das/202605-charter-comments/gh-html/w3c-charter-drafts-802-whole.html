Venue and scope: Web Haptics API

PR #795 adds Web Haptics API as a tentative DAS deliverable. There are unresolved venue and scope questions.

1. Haptics is not in the DAS WG's chartered scope

The current DAS charter scopes the WG to: power status, screen/system sleep, nearby devices, ambient light, motion/orientation, and location. Haptics is not listed.

2. Haptics is in the Web Apps WG's chartered scope

The Web Apps WG charter explicitly covers "Haptic input devices and their emitted events and/or data."

3. The CSS WG accepted haptics as a work item (March 31, 2026)

csswg-drafts#13728 was resolved at the CSS WG spring F2F: "RESOLVED: accept haptics as a work item." The resolution notes the proposal needs reworking based on points raised in the discussion.

4. No documented coordination path

The PR description says "as discussed with key stakeholders" but does not identify who, where the discussion took place, or link to minutes. There is no documented coordination between DAS, the CSS WG, and the Web Apps WG explaining why this deliverable should live in DAS rather than (or in addition to) the groups already chartered for it.

Question

How does this deliverable relate to the existing CSS WG work item and the Web Apps WG's chartered scope? What is the coordination model?
